# n0w or neVer — Owncast GitHub Website

## Upload to GitHub
Upload these three files to the root of your GitHub Pages repository:

- index.html
- style.css
- script.js

Then open your GitHub Pages URL.

## Important Owncast setting
Your Owncast server is currently configured in `script.js` and `index.html` as:

https://nowornever.ddnss.eu

If your domain changes, replace that URL in both files.

## Discord
The current Discord button uses a placeholder:

https://discord.com

Replace it with your real Discord invite link.

## Player size
The player container uses a 16:9 aspect ratio and the iframe is forced to:

width: 100%
height: 100%

Therefore the Owncast player fills the complete available frame.
